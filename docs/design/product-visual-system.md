# 产品视觉与操作规范

## 参考与产品主线

主参考为[吃一点的官方截图与预览](https://apps.apple.com/cn/app/id6761377025)。采用满屏氛围实景 Live 拼贴、白边模切食物贴纸、自由涂鸦、手写排版与真 Apple Live Photo 实况输出的视觉语言，服务“共同完善这一顿、决定吃什么、用餐、留下记录”。

来客能力和完整画布同步暂缓。当前餐次、菜谱、记录、个人资料及相关编辑页面属于本轮优化范围。

## 视觉基础

应用次级页面与编辑弹窗统一采用纯白（`#FFFFFF`）、曜石黑（`#141416`）与冷银灰（`#F4F4F6`）中性视觉基底；首页画布则完全让位于满屏氛围实景底图、透明抠图食物、白边模切贴纸与自适应透光玻璃控件。

| 角色 | 浅色模式 | 深色模式 | 用法 |
| --- | --- | --- | --- |
| 页面底色 (`AppBackground`) | `#FFFFFF` | `#0D0D0F` | 页面与纯白画室底面 |
| 内容卡片 (`CardBackground`) | `#F4F4F6` | `#1C1C1E` | 搜索框、表单块、轻量卡片与菜谱底层 |
| 主强调 (`BrandGreen`) | `#141416` | `#F2F2F5` | 主按钮与表单选中态 |
| 辅强调 (`AccentInk`) | `#2C2C2E` | `#AEAEB2` | 次级高亮与图标强调 |
| 正文 (`InkPrimary`) | `#111113` | `#F5F5F7` | 标题、正文、主要图标 |
| 次级文字 (`InkSecondary`) | `#48484A` | `#AEAEB2` | 日期、说明、分类标签 |
| 弱文字 (`InkMuted`) | `#8E8E93` | `#727278` | 占位文字、次要提示与计数 |

中文与数字使用系统字体与圆角排版，手写预设使用内置 `Noteworthy-Bold` 呈现轻松 Plog 日期手感；主导航、画布工具与选中操作采用苹果原生 SF Symbols（文字工具用衬线 `T`），由 `ProductIcon` 统一按 24 pt 网格对齐。

## 画布与工具

```text
这一顿  ( ◎ LIVE )         [ ↶ | ↷ ]    ( 🍴 吃完了 ) ( ··· )
· 11月22日 周日 · 已定下 · 4 道   头像

         [透明前景抠图 + 沿边缘白边模切轮廓]            11.22
            按主次大小与微倾角错落漂浮                 Sunday
            36 枚水粉贴纸表情 · 配闪光星点          ✦

               [对象名称 | ✨  ☷  🗑]

            ( + 加菜 )  ( ✨ 创作 )  ( 🖼 )   <-- 右侧直达更换背景；展开为 6 项带短标工具条
        ╭────────────────────────────────────╮
        │   这一顿    菜谱    记录    我的     │  <-- 自适应透光/冷银液态玻璃主导航
        ╰────────────────────────────────────╯
```

首页采用全屏无边框实景 Live 画布（`MealCanvasView`）配合两层分离式悬浮控制区：
- **自适应液态玻璃主导航与状态栏**：`RootView` 与 `MainTabView` 根据 `AppState` 状态联动——在实景/深色画布首页及「我的」全幅封面停留顶栏下方（`isProfileHeroVisible`）时自动切为白色系统状态栏；首页深色/实景底图使用深雾透光玻璃主导航（Photo-Glass），「我的」内容区通过 `.environment(\.colorScheme, .light)` 保持白卡浅色模式并在滚出封面后自动叠加安全区浅雾保护条切换回黑色状态栏；浅纸画布及「菜谱」「记录」页面保持冷银玻璃与纯白浅色模式；进入「历史详情」「菜谱详情」「做法步骤」时通过令牌化隐藏悬浮主导航，避免遮挡页面底部操作栏。
- **顶部 `LIVE` 实况控制台与创作音效开关**：左侧紧邻“这一顿”展示呼吸脉动 `LIVE` 胶囊菜单，提供「保存为实况照片」「暂停/开启实况动效」「全部轻盈动起来」「一键换排版」以及「关闭/开启创作音效」开关；深色/实景画布顶部配轻柔渐隐压暗保护条与玻璃态“吃完了”胶囊；右上 `•••` 菜单同步提供「更换背景」入口。
- **画布收放工具坞与创作套件**：默认收起为纯白 `+ 加菜` 主胶囊（浅纸底切曜石黑）、透光玻璃 `创作` 胶囊与圆形 `更换背景` 快捷按钮；展开后为带短字标签的文字（衬线 `T`）、贴纸、画笔、背景、排版、框选 6 项按钮加收起键居中浮于主导航上方。顶栏支持 **20 步画布多步撤销与重做**（有历史步骤时以联排紧凑毛玻璃 `[ ↶ | ↷ ]` 胶囊呈现并保持单行零换行）。文字面板支持快捷灵感短语、5 种文字样式（无底 / 磨砂 / 标签 / 纸贴 / 高光）及 9 档实况动效直选（“普通”采用 `minus.circle`，画布中再次点按已选纯文字可直接打开编辑）；贴纸面板按「手绘贴纸 / 我的贴图 / 表情」组织（含 16 枚原生 Plog 手绘涂鸦印章、「相册抠图 / 拍照做贴图」双入口，以及 **36 枚专属水粉白边模切手绘表情贴纸**，分精选/情绪/食光/氛围 4 组呈现，彻底替代苹果原生 Unicode 表情并向后兼容旧版文档）；涂鸦采用双排底栏（6 色点 + 笔触格 + 撤销/重做/清空 + 完成）与二次贝塞尔平滑路径，笔触扩充为 **9 种**（实线 / 点点 / 虚线 / 荧光 / 蜡笔 / 3 层光晕「霓虹」/ 闪烁「星尘」/ 流动「彩虹」/「爱心」），作画时同步触发笔尖光环、专属粒子拖尾与 `CanvasSoundEngine` 实时合成音效。
- **精选背景、相册首位与 5 档氛围滤镜**：背景面板将「从相册选」置顶在第一位，随后陈列 `66×84` 竖版预览卡片——`暖阳野餐`（默认）、`暖光咖啡`、`斜阳画纸`、`曜石暗台`、`纯白画室` 及 `海边`/`黄昏`/`夜色`，下方提供 5 档 **氛围滤镜**（`原图 / 暖阳 / 奶油 / 电影 / 清透`，实时预览并随画布持久化）与“背景虚化”调节滑杆。
- **白边模切、纯净悬浮与晶透贴纸**：菜品优先使用真实前景透明抠图（后端 `cutout_image` 或真机本地 `DishCutoutCache` 实时抠图），不再叠加常驻灰色菜名标签；由 `StickerBorderRenderer` 沿盘沿与餐具手柄自动生成光滑纯白模切贴纸边（`makeDieCutSticker`）或半透亚克力磨砂高光晶边（`makeCrystalSticker`，全透明底零不透明背景框），并可在特效面板顶部一键切换 **白边贴纸 / 纯净悬浮 / 晶透贴纸**（兼容旧版文档样式自动迁移至晶透贴纸）；特效网格支持 9 项贴纸动效（含「果冻」「星光环绕」）与 9 项文字/贴纸动效（含「果冻」「摇摆」「星闪」），新菜加入画布拥有弹落动效、双环热气星芒爆发（`CanvasFXController`）与 `CanvasSoundEngine` 五声音阶升调上菜音效，并支持非菜品元素的「复制一份」。
- **全链路 Apple Live Photo 导出与历史回放**：`LivePhotoExporter` 与 `LiveCanvasExporterHelper` 将当前背景、氛围滤镜、闪光星点、动效贴纸（含晶透贴纸、果冻、呼吸与星光环绕）、手绘贴纸、样式文字特效与霓虹/星尘/彩虹/爱心涂鸦渲染为 72 帧（3 秒 @ 24 fps）H.264 `.mov` 与带苹果配对键的 `.jpg` 静态封面，写入系统相册生成真正可长按播放的 Live Photo（导出画布纯 SwiftUI 无 `Material` 合成，零灰块零控件残留）。历史列表首张有作品餐次以 `Aspect-Fill` 全幅海报呈现且 `LIVE` 徽标单行显示；进入 `HistoryDetailView` 后 `MealCanvasSnapshotView` 支持 24 fps 动态回放，并以高对比深雾玻璃 `LIVE` / `存实况` 按钮保证浅亮实景上的可读性。

## 页面规则

- 菜谱与加菜：纯白底配合曜石黑分类药丸、`+` / `✓` 双向加减切换卡、`RemoteImageCache` 稳定图片加载，以及与当前餐次实时同步的紧凑悬浮胶囊条（「已选 N 道」+「定下这顿」/「去画布看看」）；加菜弹窗同步胶囊搜索、曜石黑切换与 `挑好了 · N 道` 动态按钮；详情页采用 `340 pt` 全幅顶部画廊、承托白卡片、6 pt 圆点食材表与曜石黑做法卡片，步骤页采用 `FlowLayout` 食材胶囊与曜石黑数字卡片；详情页与做法步骤页自动隐藏全局主导航；`RecipeEditView` 与 `CategoryManagementView` 统一纯白底、细腻边框与曜石黑主胶囊/选中态。
- 记录与清单：顶部展示总顿数/当前筛选副标题，带画布或照片的首条历史展示 `264 pt` 全幅沉浸式海报卡（`HistoryHeroCard`），无图记录呈现暖纸日历月日印记；历史详情以信息药丸、可跳转菜谱的已吃菜品行（置于备注前）、可点开 **全屏左右滑动 + 1×–4× 双指/双击缩放看大图**（`HistoryPhotoGalleryViewer`）的多图网格、`AvatarView` 参与者、“把菜加到这一顿”+“去画布”直达组成，底部栏完整无遮挡；`ShoppingListView` 统一曜石进度条、使用菜品胶囊标签与底部「复制清单发给 Ta」胶囊及轻提示；餐后评分统一星标，手工补录页统一 `SectionCard` 与分段场合选择。
- 个人与入伙：`330 pt` 全幅沉浸式可拉伸 `ProfileHeroCover` 餐桌实景封面（无模糊）自然衔接圆角白底内容页，右上方配深雾玻璃「换封面」胶囊（已设自定义封面时支持「从相册换一张」与「恢复默认封面」）与编辑圆钮，滚过封面后顶部安全区浮现毛玻璃保护层；「我们的小本本」卡片以加粗等宽数字搭配第一名曜石黑徽章、菜品占比进度条与带场景图标的场合胶囊；「常用工具」接入「定制开屏动画」入口；「我们的家」内嵌邀请码卡片集成复制/刷新快捷钮；`BrandQRCode` 统一采用曜石黑码点与白底徽标圆（入伙餐券用爱心，家宴入场券用餐具）；`InviteTicketView` 采用曜石黑票头、细腻虚线撕口与双操作按钮。
- 启动、登录与点菜房：`RootView` 在冷启动时通过 `LaunchCurtainView` 与 `LaunchCanvasPlaybackView` 播放由 `LaunchCanvasStore` 持久化的完整 DIY 实况画布（支持 `柔焦淡出 / 拉开帘幕 / 柔光揭幕 / 轻盈落星` 4 种全屏无边框出场动效、`轻快 1.1s / 标准 1.5s / 慢赏 2.2s` 3 档节奏与「跳过」退场），并在 `LaunchCanvasStudioView` 全屏开屏工坊完整复用自由画布全部创作工具（文字、手绘贴纸、相册/拍照抠图、36 枚专属水粉表情、9 种画笔涂鸦与实时特效音效、相册/内置背景含`晨光餐桌`+5 档滤镜+虚化、一键排版与 4 套开屏灵感模板、框选与 20 步多步撤销/重做）及全屏「试看」；`LoginView` 采用全幅实景暗化封面搭配白底 Apple 登录卡片；`HouseholdSetupView` 采用 `204 pt` 实景顶图与圆角白底表单；`DiningHostView`、`DiningJoinView`、`DiningGuestView` 与 `DiningDishPicker` 全面对齐餐桌实景头图+圆角白卡承托、带撕口的家宴入场券（支持 `@3x` 票图系统分享）、水粉贴纸空/收摊态、2 列点菜卡片与自适应透光玻璃「聚餐中 / 回到点菜房」胶囊，`EditProfileSheet` 同步对齐纯白/冷银/曜石黑令牌体系。
- 编辑面板：统一纯白圆角弹窗、关闭操作、冷银输入表面、曜石黑选中态与提交反馈。
- 空状态、加载和失败：说明当前状态，提供可执行的下一步。
